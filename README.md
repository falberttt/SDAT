# SDAT (SALES DATA ANALYSIS TRAINING)
This contain all training process for sales data analysis using PHYTON
Pertama, berikut ini 5 tipe data penting di PHYTON
str: teks, seperti nama customer atau produk.
int: bilangan bulat, seperti jumlah pesanan.
float: angka desimal, seperti persentase diskon 0.05.
bool: nilai benar atau salah, yaitu True atau False.
list: kumpulan beberapa nilai, yang akan kita gunakan untuk data banyak customer.
